# License decision required before public release

This source package does not currently contain a project-level `LICENSE` file. `LICENSES_AND_COMPONENTS.md` documents third-party integration boundaries; it does not grant a license to CyberForge Server Edition itself.

Choose and add a project license before publishing this repository as open source. The AIO edition currently uses MIT, so MIT is a straightforward consistency option, but that choice must be confirmed by the project owner.
